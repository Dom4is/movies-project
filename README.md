# MOVIE/SEARCH

Адаптивное приложение для поиска фильмов, сериалов и эпизодов через OMDb API.
Проект написан на React и TypeScript с использованием Redux Toolkit и React Router.

## Возможности

- Поиск по названию с задержкой запроса для уменьшения количества обращений к API
- Фильтрация по типу: фильм, сериал или эпизод
- Фильтрация по году выпуска
- Пагинация результатов
- Страница с подробной информацией о фильме
- Добавление и удаление фильмов из избранного
- Сохранение избранного и выбранной темы в `localStorage`
- Переключение между светлой и тёмной темой
- Состояния загрузки, ошибок и отсутствия результатов
- Адаптивный интерфейс для мобильных и десктопных устройств

## Технологии

- React 19

- Vite

## Запуск локально

### Требования

- Node.js 20 или новее
- npm

### Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Dom4is/movies-project.git
cd movies-project
```

2. Установите зависимости:

```bash
npm install
```

3. Создайте в корне проекта файл `.env`:

```env
VITE_OMDB_API_KEY=ваш_ключ_omdb
```

Получить бесплатный ключ можно на [OMDb API](https://www.omdbapi.com/apikey.aspx).

4. Запустите приложение:

```bash
npm run dev
```

Vite выведет адрес локального сервера в терминале, обычно это `http://localhost:5173`.

## Команды

```bash
npm run dev      # запуск сервера разработки
npm run build    # проверка типов и сборка production-версии
npm run preview  # предпросмотр production-сборки
npm run lint     # проверка ESLint
npm test         # запуск тестов Vitest
```
